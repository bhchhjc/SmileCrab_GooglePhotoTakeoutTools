## 1. 참고 앱 UI 구조 분석

### 1-1. Google Antigravity (AGY IDE)

```
┌──────────────────────────────────────────────────────────────┐
│  [≡]  Antigravity                           [Search]  [+]   │  ← 상단 헤더
├──────┬───────────────────────────────────────────────────────┤
│  🏠  │                                                       │
│  💬  │                  메인 콘텐츠 영역                      │
│  📁  │             (채팅 / 작업 결과 / 에이전트)              │
│  🔧  │                                                       │
│      │                                                       │
│  ─── │                                                       │
│  ⚙️  │                                                       │
│  👤  │                                                       │
└──────┴───────────────────────────────────────────────────────┘
  ↑ 좁은 아이콘 사이드바 (~56px)
  hover 또는 클릭 시 라벨 표시 (~240px)
```

**핵심 특징:**
- 최소 사이드바(Rail): 아이콘만 ~56px
- 확장 사이드바(Drawer): 아이콘 + 텍스트 ~240px
- 현재 선택 항목: 좌측에 컬러 액센트 바 표시
- 하단 고정: 설정(⚙️) + 사용자 프로필(👤)
- 배경: 짙은 다크 (#1E1E2E 계열)
- 콘텐츠 영역과 사이드바의 경계가 거의 없는 플랫 디자인

## 2. 현재 앱 UI 구조 (기존: 마법사 방식)

```
┌──────────────────────────────────────────────────────────────┐
│          Step 1 → Step 2 → Step 3 → Step 4                   │  ← 상단 스텝 인디케이터
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                   단일 콘텐츠 영역                            │
│           (SetupView / PreviewView / Progress / Library)     │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                       [다음]  [취소]                         │  ← 하단 버튼
└──────────────────────────────────────────────────────────────┘
```

**문제점:**
- 단방향 흐름 → 완료 후 과거 결과 재조회 불편
- 메뉴 확장 여지 없음 (설정, 히스토리 등 추가 불가)
- 전형적 설치 마법사 느낌 → 현대적 도구 느낌 없음
- 처리 완료 후 다시 처음부터 시작해야 함

## 3. 제안: 신규 사이드바 네비게이션 구조

### 3-1. 레이아웃 설계

```
┌──────────────────────────────────────────────────────────────┐
│  [≡]  📸 Google Photo Takeout Tools                          │  ← 상단 타이틀바 (커스텀 or 네이티브)
├───────────┬──────────────────────────────────────────────────┤
│           │                                                  │
│ 🏠 대시보드 │                                                  │
│           │            메인 콘텐츠 영역                       │
│ ➕ 새 작업  │         (선택된 메뉴에 따라 전환)                 │
│           │                                                  │
│ ⏱ 처리이력 │                                                  │
│           │                                                  │
│ 🖼 미디어   │                                                  │
│  라이브러리 │                                                  │
│           │                                                  │
│ ───────── │                                                  │
│           │                                                  │
│ ⚙ 설정    │                                                  │
│           │                                                  │
└───────────┴──────────────────────────────────────────────────┘
  ↑ 사이드바
  확장: ~220px (아이콘 + 텍스트)
  축소: ~56px  (아이콘만)
  [≡] 토글 버튼으로 전환
```

---

### 3-2. 메뉴 항목 정의

| 아이콘 | 메뉴명 | 역할 | 대응 뷰 |
|--------|--------|------|---------|
| 🏠 | 대시보드 (Dashboard) | 전체 현황 요약, 최근 작업 결과, 빠른 시작 버튼 | `dashboard_view.py` (신규) |
| ➕ | 새 작업 (New Job) | Takeout 폴더 선택 → 옵션 → 실행 → 완료 (내부 서브스텝) | `job_view.py` (기존 3개 뷰 통합) |
| ⏱ | 처리 이력 (History) | 과거 처리 작업 목록 (날짜별, 처리 파일 수, 소요 시간) | `history_view.py` (신규) |
| 🖼 | 미디어 라이브러리 (Library) | SQLite 기반 사진 검색/조회 | `library_view.py` (기존 유지) |
| ⚙ | 설정 (Settings) | 기본 옵션, 경로 설정, 앱 버전 | `settings_view.py` (신규) |

---

### 3-3. 각 뷰 상세 설계

#### 🏠 대시보드 (Dashboard)
```
┌──────────────────────────────────────────────────────┐
│  안녕하세요! 📸 Google Photo Takeout Tools              │
│                                                      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐           │
│  │  전체 사진 │  │  저장 절약 │  │ 마지막 작업│           │
│  │  12,345  │  │  2.3 GB  │  │  3일 전  │           │
│  └──────────┘  └──────────┘  └──────────┘           │
│                                                      │
│  [ ➕ 새 Takeout 정리 시작 ]  (Primary 버튼)          │
│                                                      │
│  최근 작업                                            │
│  ─────────────────────────────────────              │
│  · 2024-11-10  신혼여행 앨범  →  1,234개 처리         │
│  · 2024-10-05  2022년 사진   →  456개 처리           │
└──────────────────────────────────────────────────────┘
```

#### ➕ 새 작업 (New Job) — 내부 서브스텝
```
새 작업 뷰는 단일 페이지 내에서 상태 변환:
  [폴더 선택] → [옵션 & 미리보기] → [처리 중] → [완료 요약]

외부 사이드바 선택 메뉴는 변경되지 않음
(작업 중에는 다른 메뉴 클릭 시 "작업 중입니다. 중단하겠습니까?" 경고)
```

#### ⏱ 처리 이력 (History)
```
┌──────────────────────────────────────────────────────┐
│  처리 이력                                            │
│  ─────────────────────────────────────              │
│  날짜         입력 폴더    처리   중복   오류  소요시간 │
│  2024-11-10  신혼여행    1,234    23     0    2.5분  │
│  2024-10-05  2022년사진   456     8     0    0.8분  │
│                                                      │
│  [상세 보기] 클릭 시 → 해당 작업의 처리 로그 표시     │
└──────────────────────────────────────────────────────┘
```

#### 🖼 미디어 라이브러리 (Library) — 기존 유지
- SQLite FTS 검색 (키워드, 연도, 월, 종류)
- 선택 항목 Finder/Explorer 열기

#### ⚙ 설정 (Settings)
```
· 기본 출력 폴더 설정
· 기본 처리 모드 (복사 / 이동)
· 기본 폴더 전략 (YYYY/MM / YYYY / 앨범명)
· 언어 (추후 다국어 지원 고려)
· 앱 버전 정보
```

### 3-4. PySide6 구현 계획

#### 주요 컴포넌트 구조

```
MainWindow (QMainWindow)
├── CentralWidget (QWidget)
│   └── RootLayout (QHBoxLayout)
│       ├── SidebarWidget (QFrame)  ← 커스텀 위젯
│       │   ├── ToggleButton (QPushButton)       [≡]
│       │   ├── NavButtonGroup (QButtonGroup)
│       │   │   ├── NavButton: 대시보드
│       │   │   ├── NavButton: 새 작업
│       │   │   ├── NavButton: 처리 이력
│       │   │   └── NavButton: 미디어 라이브러리
│       │   └── NavButton: 설정 (하단 고정)
│       └── ContentStack (QStackedWidget)
│           ├── DashboardView
│           ├── JobView  (기존 Setup+Preview+Progress 통합)
│           ├── HistoryView
│           ├── LibraryView
│           └── SettingsView
```

#### 사이드바 토글 애니메이션

```python
# QPropertyAnimation으로 너비 변경
self.animation = QPropertyAnimation(self.sidebar, b"minimumWidth")
self.animation.setDuration(200)  # 200ms
self.animation.setEasingCurve(QEasingCurve.InOutCubic)
# 확장: 220px, 축소: 56px
```

#### 파일 구조 변화

```
src/ui/
├── __init__.py
├── main_window.py          ← 완전 재작성 (QStackedWidget + SidebarWidget)
├── theme.py                ← 사이드바 스타일 추가
├── workers.py              ← 유지
├── components/             ← 신규 폴더
│   ├── __init__.py
│   └── sidebar_widget.py   ← SidebarWidget, NavButton 커스텀 컴포넌트
└── views/
    ├── __init__.py
    ├── dashboard_view.py   ← 신규
    ├── job_view.py         ← setup + preview + progress 통합 재작성
    ├── history_view.py     ← 신규
    ├── library_view.py     ← 유지 (소수 수정)
    └── settings_view.py    ← 신규
```
